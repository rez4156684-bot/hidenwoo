# افزونه WooCommerce Booking Box Shortcode

یک افزونه قدرتمند برای نمایش فقط باکس رزرو و فیلدهای اضافی محصولات ووکامرس با استفاده از شورتکد، بدون نمایش تصاویر، توضیحات، نظرات و سایر بخش‌های محصول.

## ویژگی‌ها

✅ نمایش باکس رزرو محصول با شورتکد
✅ پشتیبانی از محصولات ساده، متغیر، گروهی و خارجی
✅ نمایش فیلدهای سفارشی و افزودنی‌های محصول
✅ پشتیبانی از تقویم و سیستم‌های رزرو
✅ طراحی ریسپانسیو و زیبا
✅ سازگار با زبان فارسی (RTL)
✅ قابل سفارشی‌سازی کامل
✅ سازگار با افزونه‌های محبوب ووکامرس

## نصب

### روش 1: نصب دستی

1. فایل‌های افزونه را در پوشه `wp-content/plugins/woocommerce-booking-box-shortcode/` کپی کنید
2. به پیشخوان وردپرس بروید
3. از منوی **افزونه‌ها** گزینه **افزونه‌های نصب شده** را انتخاب کنید
4. افزونه **WooCommerce Booking Box Shortcode** را فعال کنید

### روش 2: آپلود از پیشخوان

1. فایل‌های افزونه را در یک فایل ZIP قرار دهید
2. به **افزونه‌ها > افزودن** بروید
3. روی **بارگذاری افزونه** کلیک کنید
4. فایل ZIP را انتخاب و نصب کنید
5. افزونه را فعال کنید

## نحوه استفاده

### شورتکد پایه

برای نمایش باکس رزرو یک محصول، از شورتکد زیر استفاده کنید:

```
[wc_booking_box id="123"]
```

**توجه:** `123` را با شناسه محصول مورد نظر جایگزین کنید.

### پارامترهای شورتکد

شورتکد از پارامترهای زیر پشتیبانی می‌کند:

| پارامتر | پیش‌فرض | توضیحات |
|---------|---------|---------|
| `id` | - | شناسه محصول (الزامی) |
| `show_price` | `yes` | نمایش قیمت (`yes` یا `no`) |
| `show_stock` | `yes` | نمایش موجودی (`yes` یا `no`) |
| `show_title` | `yes` | نمایش عنوان (`yes` یا `no`) |
| `show_sku` | `no` | نمایش شناسه محصول (`yes` یا `no`) |
| `show_meta` | `yes` | نمایش متا (دسته‌بندی و برچسب) (`yes` یا `no`) |

### مثال‌های کاربردی

#### نمایش کامل با تمام اطلاعات
```
[wc_booking_box id="123" show_price="yes" show_stock="yes" show_title="yes" show_meta="yes"]
```

#### نمایش فقط فرم رزرو (بدون عنوان و قیمت)
```
[wc_booking_box id="123" show_price="no" show_title="no" show_meta="no"]
```

#### نمایش با SKU
```
[wc_booking_box id="123" show_sku="yes"]
```

## استفاده در صفحات

### در ویرایشگر بلوکی گوتنبرگ
1. بلوک **Shortcode** را اضافه کنید
2. شورتکد مورد نظر را وارد کنید
3. صفحه را ذخیره کنید

### در ویرایشگر کلاسیک
1. شورتکد را مستقیماً در محتوای صفحه قرار دهید
2. صفحه را ذخیره کنید

### در فایل‌های قالب (PHP)
```php
<?php echo do_shortcode('[wc_booking_box id="123"]'); ?>
```

## سفارشی‌سازی

### سفارشی‌سازی استایل

می‌توانید استایل‌های پیش‌فرض را با افزودن CSS سفارشی به قالب خود تغییر دهید:

```css
/* تغییر رنگ دکمه افزودن به سبد */
.wc-booking-box-form button.single_add_to_cart_button {
    background-color: #e74c3c;
}

/* تغییر عرض کانتینر */
.wc-booking-box-container {
    max-width: 800px;
}

/* تغییر رنگ قیمت */
.wc-booking-box-price .price {
    color: #e67e22;
}
```

### اضافه کردن محتوای سفارشی با Hooks

#### بعد از فرم افزودن به سبد
```php
add_action('wc_booking_box_after_add_to_cart_form', function($product) {
    echo '<div class="custom-content">محتوای سفارشی شما</div>';
});
```

#### بعد از فرم رزرو
```php
add_action('wc_booking_box_after_booking_form', function($product) {
    echo '<div class="custom-booking-info">اطلاعات رزرو سفارشی</div>';
});
```

## نکات مهم

1. **شناسه محصول:** برای پیدا کردن شناسه محصول، به لیست محصولات بروید و روی محصول موردنظر hover کنید. در آدرس URL، عدد بعد از `post=` همان ID محصول است.

2. **کش:** اگر تغییرات را نمی‌بینید، کش مرورگر و افزونه‌های کش را پاک کنید.

3. **تم:** این افزونه از استایل‌های استاندارد ووکامرس استفاده می‌کند و با اکثر قالب‌ها سازگار است.

4. **محصولات متغیر:** برای محصولات متغیر، باید کاربران ابتدا گزینه‌ها را انتخاب کنند.

## پشتیبانی از افزونه‌های رزرو

### WooCommerce Bookings

افزونه به صورت خودکار فیلدهای تقویم و رزرو را نمایش می‌دهد:

```
[wc_booking_box id="123"]
```

### YITH WooCommerce Booking

برای محصولات با قابلیت رزرو YITH:

```
[wc_booking_box id="456" show_title="yes"]
```

### WooCommerce Product Add-Ons

فیلدهای اضافی به صورت خودکار نمایش داده می‌شوند:

```
[wc_booking_box id="789"]
```

## عیب‌یابی

### باکس رزرو نمایش داده نمی‌شود

1. مطمئن شوید ووکامرس نصب و فعال است
2. ID محصول را بررسی کنید
3. کش را پاک کنید
4. JavaScript Console مرورگر را بررسی کنید

### دکمه افزودن به سبد کار نمی‌کند

1. مطمئن شوید محصول در انبار موجود است
2. برای محصولات متغیر، همه گزینه‌ها را انتخاب کنید
3. افزونه‌های دیگر را غیرفعال کنید تا تداخل را بررسی کنید

### استایل‌ها درست نمایش داده نمی‌شوند

1. کش مرورگر را پاک کنید
2. مطمئن شوید فایل CSS بارگذاری شده است (Developer Tools > Network)
3. تداخل با قالب یا افزونه‌های دیگر را بررسی کنید

## سوالات متداول

**س: آیا می‌توانم چند باکس رزرو در یک صفحه داشته باشم؟**
ج: بله، می‌توانید چندین شورتکد با ID های مختلف در یک صفحه استفاده کنید.

**س: آیا با قالب من کار می‌کند؟**
ج: بله، این افزونه با تمام قالب‌های استاندارد وردپرس سازگار است.

**س: آیا از زبان فارسی پشتیبانی می‌کند؟**
ج: بله، افزونه کاملاً RTL و فارسی است.

**س: آیا می‌توانم استایل را تغییر دهم؟**
ج: بله، می‌توانید CSS سفارشی اضافه کنید یا فایل `booking-box.css` را ویرایش کنید.
